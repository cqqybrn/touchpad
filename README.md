# TouchPad 触屏手柄

用手机触屏，像原神/崩铁手游那样操作电脑上的游戏。画面用网易 UU 远程串流到手机，本项目在 UU 画面上盖一层透明悬浮控制层，把触摸转成电脑上的**虚拟 Xbox 手柄**输入。

```
手机：UU 远程（只看画面）
     └─ 触屏手柄 App（全屏透明悬浮窗：摇杆 / 滑屏视角 / 按键）
              │  UDP 39500，完整状态包，变化即发，空闲约 30 次/秒
              ▼
电脑：pc/agent.py ──► ViGEmBus 虚拟 Xbox 360 手柄 ──► 游戏
              └──► SendInput 键盘 F1–F5（FF10 加速等）
```

## 目录

| 路径 | 内容 |
|---|---|
| `pc/agent.py` | 电脑端：收 UDP → vgamepad（ViGEmBus）；顺带 HTTP 39501 提供 `dist/` 里的 APK 下载 |
| `pc/启动电脑端.bat` | 双击启动电脑端 |
| `android/` | 手机 App，纯 Java、无第三方库、**不用 Gradle** |
| `android/build.sh` | 用 SDK 自带的 aapt2 / javac / d8 / apksigner 直接打包，输出 `dist/touchpad.apk` |
| `tools/setup.ps1` | 新电脑一键装环境（JDK17、Android SDK、vgamepad、ViGEmBus、防火墙） |

## 新电脑上手

1. 先装 **Python 3.10+** 和 **Git for Windows**。
2. 项目根目录运行：
   ```powershell
   powershell -ExecutionPolicy Bypass -File tools\setup.ps1
   ```
   中途会弹两次 UAC（装驱动、加防火墙规则），并且要你自己确认 Android SDK 许可协议。
3. 打包 APK：`bash android/build.sh`（Git Bash 里运行）。
4. 启动电脑端：双击 `pc\启动电脑端.bat`。窗口里会打印本机 IP。
5. 手机浏览器打开 `http://<电脑IP>:39501/touchpad.apk` 下载安装，App 里填电脑 IP，开启控制层。

**签名密钥没有上传**（`android/keystore.jks` 在 .gitignore 里）。新电脑第一次打包会自动生成一把新密钥，所以手机上要**先卸载旧版**再装新版；之后同一台电脑打的包可以直接覆盖安装。想无缝升级的话，把旧电脑的 `android/keystore.jks` 手动拷过去。

改代码后记得把 `android/AndroidManifest.xml` 里的 `versionCode` +1。

## 通信协议（小端）

| 类型 | 结构 |
|---|---|
| 状态 `type=1` | `"TP"`, ver=1, type=1, seq u32, buttons u16（XUSB 位）, lx ly rx ry i16, lt rt u8, keys u8（bit0–4 = F1–F5）共 21 字节 |
| ping `type=2` | `"TP"`, 1, 2, seq u32, t u64（手机 nanoTime） |
| pong `type=3` | 电脑把 ping 原样回传，手机算 RTT 显示在屏幕上方 |

- 每次发**完整状态**而不是事件，丢包不会卡键。
- 电脑端 **0.3 秒**收不到包就松开所有键、摇杆归零（断线保护）。
- 电脑只认最新的 seq，换手机/重连会自动接管。

## 手机端设计

- **每根手指按下时决定身份，直到抬起**：按钮 / 摇杆 / 右侧滑动区，多指同时操作。
- **摇杆**：默认固定在左下角（摇杆中心 2.2 倍半径内按下都算），设置里可切“浮动摇杆”。
- **右侧空白区**两种模式（由方案决定）：
  - 视角模式：手指滑动**速度**换算成右摇杆（约 25ms 平滑；加 0.16 的外圈补偿压过游戏死区）。灵敏度、上下反转可调。
  - 菜单模式：每滑 36dp 发一次十字键脉冲，轻点 = 确认。
- **布局仿米哈游**：左上角 ☰、右上角系统键、顶部正中白色横条 = 隐藏（缩成左上角小圆点，点一下恢复）、右侧 `···` 展开/收起次要键网格、右下角大主键 + 扇形副键。
- 设置页改了方案/灵敏度后回到游戏会自动重载控制层（`ACTION_RELOAD`）。

### 方案（`PadView` 构造函数里）

**崩铁（以后新游戏都以它为样板）**

| 位置 | 按钮 | 发送 |
|---|---|---|
| 右下大键 | 普攻 | X |
| 大键左 | ✓ 确认/互动 | A |
| 大键左上 | ✕ 取消 | B |
| 大键上 | 秘技 | Y |
| 左上 | ☰ 手机 | Start |
| 右上 | 轮盘（按住 + 右侧滑动选择） | LB |
| 更多 | 选择、RB、LT、RT、L3、R3 | |
| 右侧滑动 | 转视角 | 右摇杆 |

键位来源：Game8 的 HSR 手柄默认键位表（A 确认、B 取消、X 普攻、Y 秘技、Start 手机），LB 轮盘来自 Codashop 截图。用户实测“很 ok”。

**FF10（特例：没有视角，右侧滑动用来选菜单）**

这份 FF10 里 **B 是确认、A 是取消、X 是菜单**（和 Xbox 惯例相反，用户实测确认）。

| 位置 | 按钮 | 发送 |
|---|---|---|
| 右下大键 | ✓ 确认 | B |
| 大键左上 | ✕ 取消 | A |
| 左上 | ☰ 菜单 | X |
| 右上 | ⏩ 加速、▶ 开始 | F1、Start |
| 更多 | LB RB LT RT Y 选择 F2–F5 | |
| 右侧 | 滑动选菜单，轻点确认 | 十字键 / B |

## 用户定下的规则 / 偏好

- 界面要简洁，不常用的键一律收进“更多”。
- **不要用“长按确认键”做菜单之类的复用**：很多游戏长按有自己的逻辑，而且判定长按会拖慢点按。
- 摇杆默认固定在左下角。
- 新游戏都以崩铁方案为样板。

## 进度

已完成并经用户在手机上实测（同一 WiFi）：FF10、崩铁两套方案，视角手感“很 ok”（v0.3 把基础灵敏度调高了 25%）。当前版本 v0.5。

## 远程连接：结论和现状

- 手柄数据很小（几 KB/s），只看延迟不看带宽。画面继续走 UU 远程。
- 测过的情况（2026-11）：
  - 电脑在韩国的校园网里，**没有公网 IPv6**，UDP NAT 类型 **Port Restricted Cone**（适合打洞）。可以用 `easytier-cli stun` 自测。
  - EasyTier 官方公共节点 `public.easytier.top` 已经**解析不到了**，必须自建节点。
- 方案：
  - **在家（韩国家庭宽带）**：路由器通常有公网 IPv4 → 端口转发 UDP 39500 到电脑 + 路由器 DDNS（ipTIME 有 `xxx.iptime.org`），**完全不需要服务器**。手机 App 直接填域名。
  - **在学校**：需要一台牵线服务器做 EasyTier 节点（打洞成功就直连；手机走流量时可能打不通，要中转）。中转服务器离韩国越近越好。
- 用户有一台国内的阿里云服务器（地址不写在公开仓库里），想当 EasyTier 节点。**还没装**，卡在：
  1. 需要用户自己把 SSH 公钥加到服务器（不能用密码登录）；新电脑要重新生成密钥。
  2. 阿里云安全组要放行 **11010 TCP + UDP**。
  3. 如果主要在韩国玩，北京中转会绕路（多约 60–100ms），只适合牵线；中转最好用首尔/东京的服务器。
- 计划的组网参数：虚拟网段 `10.126.126.0/24`，电脑 `10.126.126.1`，手机 `10.126.126.2`（防火墙规则已经按这个网段放行）。EasyTier v2.6.4，Windows 用 `easytier-cli service install` 装成服务；安卓用官方 `app-arm64-release.apk`（以 VPN 形式运行，可以和 UU 远程同时开）。

## 环境备忘

- 如果游戏从 Steam 启动，Steam 输入可能会再接管一次虚拟手柄，出现按键重复时对该游戏关掉 Steam 输入。
- 手机：小米（澎湃 OS），需要开“显示悬浮窗”，省电策略设“无限制”，要关掉 UU 远程自带的虚拟按键。
- ViGEmBus 作者已停止维护，但 v1.22 仍然能装能用。
